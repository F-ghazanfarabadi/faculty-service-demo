# smart faculty service management Demo

## install

```bash
pip install -r requirements.txt
streamlit run app.py
```

## سه نقش، سه لینک (روی همان یک اپ)

| نقش | لینک | چه چیزی می‌بیند |
|---|---|---|
| دانشجو (ثبت شکایت) | `http://localhost:8501/?location=A11` | فقط فرم ثبت شکایت و یک پیام نتیجه ساده |
| کارکنان | `http://localhost:8501/?role=staff` | فقط مأموریت‌های خودشان، بدون جزئیات مدل |
| مدیر پروژه | `http://localhost:8501/?role=admin` | داشبورد کامل AHP/PuLP + همه شکایات و کارکنان (پشت کد دسترسی `1234`) |

بعد از دیپلوی روی Streamlit Cloud، فقط `localhost:8501` را با آدرس واقعی اپ جایگزین کنید.

## ساختار پروژه

```
app.py            رابط کاربری Streamlit (سه نقش، مسیریابی با query param)
ahp.py            محاسبه وزن معیارها و Consistency Ratio
scoring.py        تبدیل پاسخ فرم به امتیاز + تعیین سطح اولویت
optimization.py   مدل تخصیص با PuLP (برنامه‌ریزی خطی)
data/complaints.csv   دیتابیس شکایات
data/workers.csv      دیتابیس کارکنان
```

## نکته مهم امنیتی

کد دسترسی مدیر (`1234`) فقط یک قفل نمادین برای Demo است. در نسخه اصلی (استقرار واقعی)
باید با یک سیستم احراز هویت واقعی (لاگین دانشگاهی یا مشابه آن) جایگزین شود.

## محدودیت‌های شناخته‌شده Demo

- ذخیره‌سازی با CSV است، نه دیتابیس واقعی (برای نوشتن هم‌زمان امن نیست)
- سه نقش روی یک فرایند/یک فایل‌سیستم محلی کار می‌کنند؛ اگر بخواهید هرکدام را
  جدا روی Streamlit Cloud دیپلوی کنید، باید داده مشترک (SQLite/PostgreSQL یا
  Google Sheets) جایگزین فایل‌های CSV محلی شود.
- وزن‌های AHP و آستانه‌های اولویت فرضی‌اند و باید با مصاحبه خبرگان واقعی
  کالیبره شوند.
